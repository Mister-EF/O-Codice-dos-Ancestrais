# O-C-dice-dos-Ancestrais
Projeto de jogo para a comepetição de Framework-Arcade, esse jogo se trata de um puzzle-RPG medieval tecnológico onde o Caos Digital espalhou os segredos do Códice dos Ancestrais. Escolha entre Piratas, Eruditos ou Mercenários, navegue por ilhas e castelos, resolva puzzles de tecnologia, combine cartas e restaure Eldoria.
